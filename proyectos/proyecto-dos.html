Biblioteca Digital UNTEC

Sistema de gestión de catálogo y préstamos de una biblioteca, con permisos distintos según el rol de cada usuario.

Java Servlets JSP JSTL JDBC MySQL
Repositorio

Problema

La biblioteca necesita llevar el catálogo de libros y sus préstamos, pero con distintos niveles de permiso: un administrador con control total, un bibliotecario que registra libros y gestiona préstamos, y un usuario que solo puede consultar el catálogo y los préstamos activos, sin alterar nada.

Solución

Aplicación Java EE clásica construida con Servlets y JSP (JSTL en las vistas), desplegada como WAR sobre Tomcat, con acceso a MySQL vía JDBC siguiendo el patrón DAO. Un Filter (AuthFilter) centraliza todo el control de acceso de la aplicación: deja pasar libremente las rutas públicas, bloquea el acceso directo por URL a las pantallas de alta según el rol, exige sesión activa para el resto, y guarda la URL solicitada antes de redirigir al login para devolver al usuario exactamente a donde quería ir una vez autenticado.

Detalles técnicos

  • Tres roles (ADMIN, BIBLIOTECARIO, USUARIO) con permisos distintos sobre libros y préstamos, validados en un único filtro para toda la app.
  • CRUD de libros y préstamos con las reglas de negocio en el servlet (registrar, devolver, eliminar).
  • Acceso a datos con el patrón DAO y JDBC puro, sin ORM, incluyendo un JOIN para mostrar el título del libro en cada préstamo sin consultas extra.
  • Manejo de errores con logging (java.util.logging) en lugar de printStackTrace().
  • Login con redirección a la URL originalmente solicitada tras autenticarse.
