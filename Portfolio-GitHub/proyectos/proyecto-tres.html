Alke Wallet

Billetera digital simulada para depositar, retirar, transferir a contactos y revisar el historial de movimientos, sin backend.

JavaScript jQuery Bootstrap HTML5 CSS3
Repositorio

Problema

Practicar la construcción de un flujo completo de aplicación —login, múltiples pantallas, validación de formularios y persistencia de estado entre sesiones— usando únicamente el navegador, sin depender de un backend ni una base de datos real.

Solución

Interfaz multi-página con Bootstrap y jQuery: login, menú, depósito, retiro, transferencia a contactos e historial de movimientos. Todo el estado (usuario, saldo, contactos, transacciones) se persiste en localStorage a través de un módulo de almacenamiento propio (AlkeStorage) que centraliza la lectura, escritura y creación de transacciones, con manejo de errores si el storage no está disponible. Los montos se formatean en pesos chilenos con Intl.NumberFormat, las transferencias permiten buscar y elegir un contacto desde una lista filtrable, y cada pantalla protegida redirige al login si no detecta un usuario autenticado en sesión.

Detalles técnicos

  • Estado global en localStorage con serialización/deserialización segura y datos iniciales de respaldo si el storage falla o está corrupto.
  • Guard de sesión (requireAuth) reutilizado en cada pantalla protegida.
  • Búsqueda de contactos en vivo, filtrando por nombre o email mientras se escribe.
  • Formato de moneda localizado (CLP) con Intl.NumberFormat.
  • Historial de transacciones con IDs autoincrementales generados en el cliente.
