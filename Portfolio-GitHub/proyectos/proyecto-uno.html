Spring Edu Manager

Plataforma de gestión académica para administrar estudiantes y cursos, con acceso diferenciado por rol y una API REST propia lista para integraciones.

Java Spring Boot Spring Security Spring Data JPA Thymeleaf MySQL Bean Validation
Repositorio

Problema

Una institución educativa necesita administrar estudiantes y cursos con reglas de acceso claras: un administrador que gestiona todo y un usuario que solo consulta. Además, necesita validar datos reales (como el RUT del estudiante) y dejar esa información disponible tanto para uso interno como para integraciones futuras con otros sistemas.

Solución

Arquitectura en capas (controller / service / repository / DTO) sobre Spring Boot. Spring Security controla el acceso por rol: el ADMIN gestiona estudiantes y cursos de punta a punta, mientras que el rol USER solo puede consultar cursos. Spring Data JPA junto a MySQL manejan la persistencia, y un validador de RUT chileno propio (implementado como anotación de Bean Validation) verifica el dígito verificador antes de guardar cualquier dato. Un @ControllerAdvice centraliza el manejo de errores para no repetir try/catch en cada controlador. La aplicación expone dos frentes: vistas Thymeleaf para el uso diario y una API REST (/api/estudiantes, /api/cursos) con respuestas envueltas en un DTO uniforme, pensada para integrarse con otros sistemas o un futuro frontend independiente.

Detalles técnicos

  • Autenticación con formulario propio y control de acceso por rol vía Spring Security.
  • Separación DTO de entrada/salida (EstudianteDTO / EstudianteResponseDTO) para no exponer las entidades JPA directamente.
  • Validación de RUT chileno con anotación de validación personalizada (@ValidRut).
  • Manejo global de excepciones (recurso no encontrado, rutas inexistentes) con páginas de error propias.
  • API REST documentada por convención, con respuestas consistentes mediante un wrapper ApiResponse<T>.
